# NodeLabs
A graph theory learning tool built with Godot and C#. Users can build and
generate graphs, create their own, test their knowledge in quiz mode and compare scores on a
leaderboard.

## Features
	• Create custom graphs by adding nodes, edges, weights and directions.
	•  Generate graphs automatically.
	•  Quiz mode on graphs (Survival mode).
	•  User accounts and a leaderboard.
	•  In-app instructions.

## Requirements
- Godot 4.x, **.NET (C#) version**
- .NET SDK 8.0.403 

## Running the project
1. Download the compressed zip folder and extract.
2. Open Godot, click **Import**, and select the folder.
3. Press **F5** to run.
